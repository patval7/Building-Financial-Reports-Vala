# Building Financial Reports

This is a data analysis project I completed on **[DataCamp.com](https://www.datacamp.com/)** as part of a hands-on course. The project focuses on evaluating the financial health of companies from different industries using real-world accounting data.

The analysis is based on two datasets — **Balance_Sheet.xlsx** and **Income_Statement.xlsx** — each containing detailed yearly financial information for companies, along with industry classification (`tech`, `fmcg`, `real_est`).

## Project Objectives
- Calculate financial ratios such as **leverage ratio** and **profitability ratio**
- Compare financial performance across industry types
- Visualize key relationships between financial indicators
- Provide actionable insights to support decision-making for a hedge fund manager

This project demonstrates my ability to combine **finance**, **data analysis**, and **Python programming** to extract insights from raw data — with a strong emphasis on real-world application.

## Technologies Used
- **Python 3.10+**
- **Pandas** — data manipulation
- **NumPy** — mathematical computations
- **Matplotlib** and **Seaborn** — data visualization
- **Jupyter Notebook** — interactive analysis environment
